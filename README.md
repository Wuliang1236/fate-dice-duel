## 已交付功能

- 六枚符号骰、每回合最多三次投掷、保留骰子、轮流行动；双方各 15 点生命。
- 斧头 / 头盔、箭矢 / 圆盾对应攻防；手套偷能量；金色虚线框获得能量。
- 索尔怒袭：消耗 4 / 8 / 12 能量，造成 2 / 5 / 8 点伤害；结算时能量不足会失效。
- 双人在线房间、邀请码、准备、下一回合、隐藏恩惠选择、离线暂停与超时判负。
- 最终增强版：能量光粒子、手套抓取、斧箭飞行、格挡与受击提示、按等级变化的雷电；可跳过结算、关闭特效。
- Web Audio 合成音效：能量、手套、斧箭、格挡、受击及不同等级雷声；具有独立静音开关，需先经玩家操作激活。

AI 对战仅讨论过方案，尚未实现。临时隧道分享不是真正的 WebRTC P2P。音效通过代码合成，没有独立 MP3 / WAV 文件。

## 两种运行方式

| 方案 | 最终 ZIP 内源码路径 | 房间保存 | 运行条件 |
| --- | --- | --- | --- |
| 自有云服务器 / 本机 | repository/Projects/命运之戏 | 单进程内存；服务重启会清空当前对局 | Node.js 22 或更新版本，无第三方运行依赖 |
| Sites / Workers + D1 | repository/Projects/命运之戏/cloud | D1 数据库存储与 revision 并发校验 | 安装锁定依赖，并配置对应托管环境和 D1 |

两种方案的房间不互通。完整源码以 ZIP 形式保存，仓库顶层文档用于浏览和恢复指引。

### 自有服务器版

在解压后的 `repository/Projects/命运之戏` 中运行：

```bash
node --test test/game.test.mjs test/audio.test.mjs
node server.mjs
```

默认访问 `http://localhost:3000/`，可用 `PORT` 环境变量换端口。对话中 Ubuntu 服务器使用 8088，systemd 示例、端口检查和回退边界见 [Ubuntu 部署说明](DEPLOYMENT-UBUNTU.md)。首次在新服务器使用前核对现有目录、服务和端口。

### Sites 云端版

在 `repository/Projects/命运之戏/cloud` 中运行：

```bash
node --test test/api.test.mjs
npm ci
node scripts/run-framework.mjs build
```

首次部署需要配置 D1 并正确应用已有迁移。同步父工程使用 `node scripts/sync-game.mjs`，请保留父子目录层级。归档不内置 node_modules，但保留依赖锁文件和第三方许可证。
